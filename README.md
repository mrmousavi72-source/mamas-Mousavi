# قلمرو

بازی تصرف قلمرو روی نقشه‌ی ایران. بدوید یا رکاب بزنید، حلقه ببندید و هر چه داخل حلقه است مال شما می‌شود. اگر حلقه‌ی شما روی قلمروی کس دیگری بیفتد، آن بخش را از او می‌گیرید.

این پروژه از روی رفتار عمومی اپ‌های «تصرف قلمرو با دویدن» (مثل INTVL) از صفر نوشته شده و هیچ کد، طراحی یا برندی از آن‌ها در آن نیست.

## قابلیت‌ها

- **وب‌اپ نصب‌شدنی (PWA)**: روی اندروید و iOS از مرورگر «افزودن به صفحه‌ی اصلی»؛ نیازی به گوگل‌پلی یا اپ‌استور نیست.
- **فارسی و راست‌به‌چپ** با فونت وزیرمتن و اعداد فارسی.
- **ثبت مسیر با GPS**: نقاط با دقت بدتر از ۵۰ متر نادیده گرفته می‌شوند. صفحه روشن می‌ماند (Wake Lock). اگر صفحه بسته شود، فعالیت نیمه‌کاره بازیابی می‌شود.
- **تصرف**: مسیر باید در فاصله‌ی ۲۰۰ متری نقطه‌ی شروع تمام شود. حلقه‌های ۸ شکل و مسیرهای رفت‌وبرگشتی درست حساب می‌شوند.
- **نبرد**: هر بخشی از قلمروی دیگران که داخل حلقه‌ی شما باشد، به شما می‌رسد. تکه‌های کوچک‌تر از ۵۰۰ متر مربع که باقی بمانند حذف می‌شوند.
- **دو نقشه‌ی جدا**: دویدن و دوچرخه. دونده‌ها فقط با دونده‌ها رقابت می‌کنند.
- **رتبه‌بندی و آخرین نبردها**، پروفایل با آمار مسافت و فعالیت‌ها.
- **ضدتقلب پایه**: رد کردن سرعت غیرعادی (بیش از ۲۵ کیلومتر بر ساعت برای دویدن و ۷۰ برای دوچرخه)، مسیرهای بیرون از ایران و حلقه‌های بیش از ۲۰ کیلومتر مربع.

## اجرا

نیازمند Node.js نسخه‌ی ۲۲.۱۳ یا بالاتر (از SQLite داخلی Node استفاده می‌شود).

```bash
npm install
npm start          # http://localhost:3000
npm run dev        # همراه با «رسم مسیر آزمایشی» برای تست بدون دویدن
npm test
```

| متغیر محیطی | پیش‌فرض | توضیح |
|---|---|---|
| `PORT` | `3000` | پورت سرور |
| `DB_PATH` | `data.sqlite` | مسیر فایل دیتابیس |
| `ALLOW_SIMULATION` | `false` | با `true` می‌شود مسیر را با کلیک روی نقشه رسم کرد. در نسخه‌ی عمومی خاموش بماند |

## پیش از انتشار عمومی

- **HTTPS الزامی است**: مرورگرها موقعیت مکانی را فقط روی HTTPS (یا localhost) می‌دهند.
- **کاشی‌های نقشه**: الان مستقیم از `tile.openstreetmap.org` خوانده می‌شوند. سیاست استفاده‌ی OSM ترافیک زیاد را مجاز نمی‌داند. برای کاربران واقعی از سرویس نقشه‌ی نشان یا Map.ir، یک ارائه‌دهنده‌ی تجاری، یا سرور کاشی خودتان استفاده کنید. فقط آدرس `L.tileLayer` در `public/app.js` باید عوض شود.
- **محدودیت GPS در پس‌زمینه**: وب‌اپ‌ها وقتی صفحه خاموش است یا اپ دیگری باز است موقعیت نمی‌گیرند، به‌خصوص در iOS. برای ثبت مسیر در پس‌زمینه باید نسخه‌ی موبایل بومی (مثلاً با Capacitor) ساخت. بک‌اند همین می‌ماند.
- **ضدتقلب** فعلاً پایه است. GPS جعلی را تشخیص نمی‌دهد.
- **دیتابیس**: SQLite برای شروع و چند هزار کاربر کافی است. برای مقیاس بزرگ‌تر PostgreSQL + PostGIS پیشنهاد می‌شود.
- **محدودیت نرخ درخواست** برای ورود و ثبت‌نام هنوز اضافه نشده است.

## ساختار

```
server/
  index.js      راه‌اندازی سرور
  app.js        مسیرهای API
  territory.js  منطق بازی: اعتبارسنجی مسیر، ساخت چندضلعی، تصرف
  iran.js       مرز تقریبی ایران
  auth.js       رمز عبور (scrypt) و توکن نشست
  db.js         جدول‌های SQLite
public/         رابط کاربری (Leaflet)، manifest و service worker
test/           تست‌ها
```

## API

| مسیر | توضیح |
|---|---|
| `POST /api/register`، `POST /api/login` | دریافت توکن (`{ username, password }`) |
| `GET /api/me` | آمار کاربر (نیاز به توکن) |
| `GET /api/territories?mode=run&bbox=w,s,e,n` | قلمروها به صورت GeoJSON |
| `POST /api/activities` | ثبت فعالیت: `{ mode, points: [{ lat, lng, t }] }` |
| `GET /api/leaderboard?mode=run` | رتبه‌بندی بر اساس مساحت |
| `GET /api/feed?mode=run` | آخرین تصرف‌ها |
